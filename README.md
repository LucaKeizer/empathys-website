# Empathys Website

Small full-stack website built for Empathys.

The site includes a product page for a book, a shopping cart, and a checkout flow with payments. It also has basic pages for courses, contact, and company info.

## What it does

* Simple webshop (add to cart, checkout, order confirmation)
* Payment flow using Stripe
* Contact form that sends emails
* Static pages for courses and information

## Structure

* `public/` → images and static assets
* `src/app/` → pages + API routes
* `src/components/` → UI components
* `src/contexts/` → cart state

## Notes

Built as a practical project for a real use case. Focus was on getting a complete flow working end-to-end rather than perfect architecture.
